# Code of Conduct

## Our Pledge

We are committed to making participation in this project respectful and welcoming for everyone.

## Expected Behavior

- Be respectful.
- Be constructive.
- Help newcomers.
- Focus on technical discussions.

## Unacceptable Behavior

- Harassment
- Personal attacks
- Discrimination
- Offensive language

## Enforcement

Project maintainers may remove contributions that violate these guidelines.
