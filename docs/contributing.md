# Contribuindo

Obrigado por querer contribuir com o Laravel Domain Generator.

---

## Clonando

```bash
git clone https://github.com/Diegosny/laravel-domain-generator.git
```

---

## Instalação

```bash
composer install

npm install
```

---

## Executando a documentação

```bash
npm run docs:dev
```

---

## Padrões

- PSR-12
- Tipagem forte
- Métodos curtos
- Sem lógica HTTP no domínio

---

## Pull Requests

1. Crie uma branch.
2. Faça alterações.
3. Atualize a documentação.
4. Abra um PR.

---

## Commits

Recomendado:

```text
feat:
fix:
docs:
refactor:
test:
```
